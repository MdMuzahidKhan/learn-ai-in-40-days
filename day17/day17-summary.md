# Day 17 Summary

## Topic
Cloud deployment fundamentals.

## What was implemented
- Deployed the Book API to Render.
- Also explored deployment on AWS EC2.
- Verified the API using public URLs and IP-based access.
- Connected Postman to the deployed API.

## Deployment concepts
- Compute: the running cloud service or EC2 instance.
- Storage: deployed files and temporary runtime data.
- Networking: public URL or public IP plus open port access.

## Result
- The API was reachable outside the local machine.
