# Day 1 Notes

## What Is Git?

Git is a version control system that tracks changes in files over time. It helps developers save history, create branches, and collaborate without overwriting each other's work.

## Commands Practiced

- `git status`
- `git add`
- `git commit`
- `git log --oneline`
- `git branch`
- `git checkout -b`

## Key Learning

`git add` moves changes into the staging area, while `git commit` saves the staged snapshot into the repository history.

## One Confusing Part

At first, it was confusing to understand the difference between modified files and staged files. Running `git status` helped clarify what would be included in the next commit.
